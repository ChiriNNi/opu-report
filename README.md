# Отчёт «План / факт ОПУ по партнёрам»

Страница показывает план ОПУ партнёра (численность операторов по выгрузке) и факт
отметок по дням (API Dream Square), по умолчанию — за три последних дня.

- `index.html` — сама страница. При открытии и по кнопке **Обновить** берёт
  живые данные из `/api/data`, без перезагрузки страницы. Если API недоступен,
  показывает сохранённый `data.json` и пишет об этом рядом с кнопкой.
- Вкладка **Операторы за день** (`#operators`, ссылку можно давать кураторам) — по каждому
  партнёру отчёта: кто из операторов отметился (время, объект, моб./ручн.) и кто ещё нет.
  Поиск по партнёру или ФИО, выбор даты, сегодняшний день обновляется сам раз в 5 минут.
  По клику на партнёра — окно со списком «не отметились / отметились», телефонами (звонок
  в одно касание) и кнопкой «Скопировать список» для мессенджера.
  Данные — `api/operators.py` → метод API `reports/attendance/operators`. Телефоны
  включаются/выключаются `SHOW_PHONES` в `build_data.py`.
- В основной таблице клик по имени партнёра (▸) раскрывает отметки по городам за выбранный
  период — из API `reports/attendance?groupBy=city`.
- `api/data.py` — функция Vercel: на каждый запрос заново собирает план/факт
  из API Dream Square (обычно меньше секунды).
- `build_data.py` — сборщик: дёргает API по каждому дню заново, поэтому
  прошлые дни тоже пересчитываются, а не только сегодняшний.
- `data.json` — запасной снимок данных; обновляется вручную запуском `build_data.py`.
- `plan_daily.json` — список партнёров отчёта, число объектов и начало календаря.
- `plan_opu.json` — план ОПУ по партнёрам отчёта (собирается `plan_from_xlsx.py`).
  План 80% считается от него.

## Ключи API

Хостинг — Vercel, проект подключён к ветке `main`. Ключи лежат в
Vercel → Settings → Environment Variables (`DS_CLIENT_ID`, `DS_CLIENT_SECRET`),
в файлы репозитория они не попадают. После изменения переменных нужен Redeploy.

## Локальный запуск

```bash
DS_CLIENT_ID=... DS_CLIENT_SECRET=... python build_data.py
python -m http.server 8000        # затем открыть http://localhost:8000
```

Обычный `http.server` отдаёт только статику: `/api/data` работает на Vercel
(или через `vercel dev`), локально страница покажет снимок из `data.json`.

Открывать `index.html` двойным кликом нельзя: браузер запрещает `fetch` к
локальному файлу, нужен любой http-сервер.

## Новый план ОПУ

План берётся из выгрузки численности операторов (колонки `ФИО_П`, `org_name`,
`Месяц`, `Кол-во людей`, `ФИО людей`) за последний месяц в файле. Учитываются
только партнёры отчёта; соответствие имён — словарь `MATCH` в `plan_from_xlsx.py`.

```bash
pip install openpyxl
python plan_from_xlsx.py "март сентябрь.xlsx"   # перезапишет plan_opu.json
```

Затем закоммитить `plan_opu.json` в `main` — Vercel пересоберёт сайт.
