# Отчёт «План / факт ОПУ по партнёрам»

Страница показывает план на день (из разбивки по партнёрам) против факта отметок
операторов (API Dream Square), по умолчанию — за три последних дня.

- `index.html` — сама страница. При открытии и по кнопке **Обновить** берёт
  живые данные из `/api/data`, без перезагрузки страницы. Если API недоступен,
  показывает сохранённый `data.json` и пишет об этом рядом с кнопкой.
- `api/data.py` — функция Vercel: на каждый запрос заново собирает план/факт
  из API Dream Square (обычно меньше секунды).
- `build_data.py` — сборщик: дёргает API по каждому дню заново, поэтому
  прошлые дни тоже пересчитываются, а не только сегодняшний.
- `data.json` — запасной снимок данных; обновляется вручную запуском `build_data.py`.
- `plan_daily.json` — план на день по партнёрам. Когда разбивка заканчивается,
  на следующих днях держится план её последнего дня.

## Ключи API

Хостинг — Vercel, проект подключён к ветке `main`. Ключи лежат в
Vercel → Settings → Environment Variables (`DS_CLIENT_ID`, `DS_CLIENT_SECRET`),
в файлы репозитория они не попадают. После изменения переменных нужен Redeploy.

## Локальный запуск

```bash
DS_CLIENT_ID=... DS_CLIENT_SECRET=... python build_data.py
python -m http.server 8000        # затем открыть http://localhost:8000
```

Обычный `http.server` отдаёт только статику: `/api/data` работает на Vercel
(или через `vercel dev`), локально страница покажет снимок из `data.json`.

Открывать `index.html` двойным кликом нельзя: браузер запрещает `fetch` к
локальному файлу, нужен любой http-сервер.

## Новая разбивка плана

Замените `plan_daily.json` — формат: `days` (даты YYYY-MM-DD), `rows`
(`name`, `obj`, `plan`, `plan80`, `daily` — план по дням).
